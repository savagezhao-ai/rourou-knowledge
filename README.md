# 🐉 肉肉的知识宝库

一个给小朋友看的中文科普网站：不堆「趣味知识」，而是按**第一性原理**把一件事拆到底——多问为什么、怎么做到的，用孩子听得懂的语言讲透因果。

> 🌐 在线阅读：**https://savagezhao-ai.github.io/rourou-knowledge/**

## 这是什么

- **66 篇科普文章**，覆盖 6 大分类：🌍 自然地球（27）、🚀 科技探索（13）、🌱 环保健康（11）、🧮 趣味数学（4）、🚂 交通工程（4）、🛡️ 安全常识（4）
- **3 个互动小玩具** 🧸：鹈鹕骑单车（3D 动画）、太阳系漫游（3D）、太阳起落演示
- 每篇文章配 **5 幅 AI 插图**，全部本地模型生成（Flux.2 Klein / Qwen-Image-2.1，Mac + ComfyUI）
- 纯静态 HTML，零依赖、零广告、离线也能看

## 讲什么、怎么讲

选题来自孩子会问的问题，比如：

- 🐌 能吃的蜗牛和鲍鱼——一对背壳的表兄弟
- ⛈️ 冬天下雪为何不打雷——天上的「静电工厂」放寒假了
- 🌧️ 天上的雨干净么？
- 🧠 大脑里的两个小工人：前额叶和杏仁核

写法上坚持三条：

1. **追根问底**：每个核心概念向下钻两三层因果，不停留在「是什么」
2. **打比方、做实验**：用家里的东西就能验证的知识，比结论更值钱
3. **留反例**：罕见的例外（比如「雷打雪」）往往是最好的思考训练

## 网站结构

```
├── index.html          # 首页（文章列表 + 分类筛选）
├── <yymmdd>/           # 每篇文章一个目录（同日多篇加 -2、-3 后缀）
│   ├── index.html
│   └── scene_0X.webp   # 5 幅插图（本地原图为 PNG，仓库为 WebP）
└── toy/<slug>-<yymmdd>/# 互动小玩具（自包含单文件 HTML）
```
